TypeScript Assignment 01:

This project contains solutions to the first TypeScript assignment, including several coding problems and two technical blog posts. The goal of this assignment is to demonstrate a solid understanding of TypeScript's core concepts, Type safety, and Object-Oriented Programming (OOP).

-->Project Structure
solutions.ts: Contains the logic for all 7 coding problems (Filtering, Reversing, Classes, Generics, etc.).

blog-1.md: A blog post explaining the Four Pillars of OOP in TypeScript.

blog-2.md: A short blog post about Pick and Omit utility types and the DRY principle.

--> How to Run the Solutions
To run the TypeScript solutions locally, follow these steps:

1) Make sure you have Node.js and TypeScript installed.

2) Install ts-node globally if you haven't already:

Bash
npm install -g ts-node
Run the solutions file using the following command:

Bash
ts-node src/solutions.ts

-->Features Covered
Type Narrowing: Checking types at runtime for safe data handling.

Generics: Building reusable and strictly typed functions.

OOP Principles: Implementing Inheritance and Class structures.

Utility Types: Using Pick and Omit to keep code clean and dry.

Array Methods: Practical use of .filter(), .includes(), and .map().

-->Blog Posts Summary
Blog 1: Explains how Inheritance, Polymorphism, Abstraction, and Encapsulation help manage large-scale codebases.

Blog 2: Discusses how to prevent code duplication using Pick and Omit utility types.
